# 内推岗位与海报公开接口

其他平台用开发者中心的长期 API Key 查询在招岗位，并生成内推链接和二维码。密钥不会自动过期，主动轮换后旧密钥立即失效。

不要调用登录态接口 `/api/referrals/positions` 和 `/api/referrals/campaigns`。对外只使用本文的两个公开接口。

## 通用约定

| 项目 | 说明 |
| --- | --- |
| 服务地址 | `https://r5vd-1031.studio.fengbao.com` |
| 鉴权 | 请求头 `X-API-Key` |
| 密钥 | 与简历公开接口、月度招聘需求接口共用，在开发者中心查看 |
| 有效期 | 长期有效，直到主动轮换 |
| 登录 | 不需要 |

错误响应：

| HTTP 状态 | 说明 |
| --- | --- |
| `400` | 参数缺失、手机号格式错误，或公开页面地址无效 |
| `401` | 未传 Key、Key 错误，或 Key 已被轮换 |

## 1. 查询在招岗位

```http
GET https://r5vd-1031.studio.fengbao.com/api/public/referral-api/positions
```

只返回发布状态为「招聘中」或「已发布」，且招聘状态不是「暂停招聘」的岗位。

### 请求示例

```bash
curl "https://r5vd-1031.studio.fengbao.com/api/public/referral-api/positions" \
  -H "X-API-Key: rf_live_替换为实际密钥" \
  -H "Accept: application/json"
```

```python
import os
import requests

response = requests.get(
    "https://r5vd-1031.studio.fengbao.com/api/public/referral-api/positions",
    headers={
        "X-API-Key": os.environ["RESUME_API_KEY"],
        "Accept": "application/json",
    },
    timeout=30,
)
response.raise_for_status()
positions = response.json()["positions"]
```

### 成功响应

HTTP `200`，`Content-Type: application/json`。

```json
{
  "keyValidity": "长期有效，直到主动轮换密钥",
  "positions": [
    {
      "id": "岗位ID",
      "name": "商务开发",
      "department": "销售部",
      "responsibilities": "工作职责",
      "requirements": "任职要求",
      "salaryText": "8k-12k",
      "minSalary": 8000,
      "maxSalary": 12000
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `positions[].id` | 岗位 ID，生成海报时可传给 `positionId` |
| `positions[].name` | 岗位名称 |
| `positions[].department` | 部门 |
| `positions[].responsibilities` | 工作职责 |
| `positions[].requirements` | 任职要求 |
| `positions[].salaryText` | 薪资文本 |
| `positions[].minSalary` | 最低薪资 |
| `positions[].maxSalary` | 最高薪资 |

## 2. 生成内推海报

```http
POST https://r5vd-1031.studio.fengbao.com/api/public/referral-api/campaigns
```

请求体为 JSON。

### 参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `referrerName` | 是 | 推荐人姓名 |
| `referrerMobile` | 是 | 推荐人手机号，必须是 11 位大陆手机号 |
| `publicBaseUrl` | 是 | 候选人打开内推页的基地址，必须使用 `http` 或 `https` |
| `name` | 否 | 活动名称。不传时使用「推荐人姓名 + 内推」 |
| `role` | 否 | 岗位名称。不传时为「全部岗位」 |
| `positionId` | 否 | 查询岗位接口返回的岗位 ID |
| `department` | 否 | 岗位部门 |
| `referrerDepartment` | 否 | 推荐人部门 |
| `description` | 否 | 活动说明 |

同一推荐人、同一手机号、同一岗位名称再次调用时，返回已有海报，不会重复创建。

### 请求示例

```bash
curl -X POST "https://r5vd-1031.studio.fengbao.com/api/public/referral-api/campaigns" \
  -H "X-API-Key: rf_live_替换为实际密钥" \
  -H "Content-Type: application/json" \
  -d "{\"name\":\"张三内推\",\"role\":\"商务开发\",\"department\":\"销售部\",\"positionId\":\"岗位ID\",\"publicBaseUrl\":\"https://r5vd-1031.studio.fengbao.com/\",\"referrerName\":\"张三\",\"referrerMobile\":\"13800138000\",\"referrerDepartment\":\"销售部\"}"
```

```python
import os
import requests

response = requests.post(
    "https://r5vd-1031.studio.fengbao.com/api/public/referral-api/campaigns",
    headers={
        "X-API-Key": os.environ["RESUME_API_KEY"],
        "Content-Type": "application/json",
    },
    json={
        "name": "张三内推",
        "role": "商务开发",
        "department": "销售部",
        "positionId": "岗位ID",
        "publicBaseUrl": "https://r5vd-1031.studio.fengbao.com/",
        "referrerName": "张三",
        "referrerMobile": "13800138000",
        "referrerDepartment": "销售部",
    },
    timeout=30,
)
response.raise_for_status()
poster = response.json()
```

### 成功响应

HTTP `201`，`Content-Type: application/json`。

```json
{
  "campaignId": "refcampaign_xxx",
  "publicUrl": "https://r5vd-1031.studio.fengbao.com/?referral_token=xxx",
  "qrCode": "data:image/png;base64,...",
  "token": "xxx",
  "status": "启用",
  "reused": false,
  "referrerName": "张三",
  "referrerMobile": "13800138000",
  "keyValidity": "长期有效，直到主动轮换密钥"
}
```

| 字段 | 说明 |
| --- | --- |
| `campaignId` | 内推活动 ID |
| `publicUrl` | 候选人扫码后打开的内推页面 |
| `qrCode` | PNG 二维码的 Data URL，可直接作为图片地址 |
| `token` | 新生成时返回。复用已有海报时为空，以 `publicUrl` 为准 |
| `status` | 固定为「启用」 |
| `reused` | `false` 表示新生成，`true` 表示复用已有海报 |
| `referrerName` | 推荐人姓名 |
| `referrerMobile` | 推荐人手机号 |

`qrCode` 可以直接放进 HTML：

```html
<img src="data:image/png;base64,..." alt="内推海报二维码">
```
