# 方片招聘网站结构方案

## 建设目标
输出一套可在 ARP Studio 内搭建的招聘网站，作为候选人的统一流量入口，与招聘中台和候选人 H5 打通。

## 前台页面结构
1. 官网首页：品牌 Banner、热招岗位、公司介绍、文化福利、员工故事、校招入口、达人岗位专题入口、FAQ、底部导航。
2. 职位列表页：关键词搜索、事业部/城市/岗位类别筛选、校招/社招切换、岗位卡片列表。
3. 职位详情页：岗位 JD、职责要求、团队介绍、办公地点、福利、相关推荐、立即投递。
4. 关于方片：公司介绍、业务版图、发展历程、企业文化、办公环境、福利制度。
5. 校招专区：校招项目、学校专场、训练营、FAQ、网申入口。
6. 达人岗位专题：达人孵化、自孵、内容运营、商务变现岗位专题与赛道说明。
7. 投递进度查询：候选人通过手机号/邮箱验证码登录后查看投递、面试、Offer、入职进度。

## 后台 CMS 页面
1. 官网首页配置：维护 Banner、模块排序、品牌文案、热招岗位、FAQ。
2. 职位专题配置：维护校招专区、达人岗位专题、内推专题等页面内容。
3. 官网内容发布：预览、发布、下线、版本管理。

## 数据联动规则
- 已通过审批且状态=已发布 的岗位自动同步到职位列表和职位详情页。
- 校招项目表同步到校招专区；达人岗位标签同步到达人岗位专题页。
- 投递成功后直接进入简历库主档，并向候选人发送站内消息/短信。
- 投递进度查询页读取候选人主档与流程状态表，不单独建状态源。

## 搭建要求
- 招聘网站需区分 PC 官网与移动 H5 自适应展示，但共用一套内容配置和岗位数据源。
- 所有投递按钮最终落到候选人投递页；所有状态查询最终落到候选人进度中心。
- 官网不展示未发布、已关闭、暂停招聘的岗位。
- 官网内容更新需保留版本与发布日志。
