# 方片内部招聘中台 ARP 执行指令

## 执行目标
在 ARP Studio 低代码平台内完成招聘中台搭建，对标北森招聘系统，移除背调模块，并打通 ARP 主平台、方片商学院、达人数据中台。

## 执行顺序
1. 先读取 `方片内部招聘中台ARP配置清单.xlsx` 的 `01-系统定位角色`、`02-角色清单`、`03-模块蓝图`，建立系统边界和角色。
2. 按 `04-菜单导航` 创建一级/二级页面；按 `05-页面配置` 创建每个页面的表单、列表、筛选、批量操作和通知入口。
3. 按 `06-审批流` 配置招聘需求、渠道上线、Offer、AI配置、校招项目、内推奖励等流程。
4. 按 `07-权限矩阵` 配置页面权限、按钮权限、数据范围、字段脱敏、导出权限和审批权限。
5. 按 `08-数据联动` 对接 ARP 主平台、方片商学院、达人数据中台，并配置内部自动联动。
6. 按 `09-AI配置` 完成两类 Skill 复用和三类新 AI 工作流搭建，确保 AI 输出可人工编辑。
7. 按 `10-BI看板`、`11-H5结构`、`12-通知待办`、`13-操作日志`、`15-招聘网站` 完成看板、候选人端、官网和审计模块。
8. 上线前逐项执行 `14-发布清单`，必做项全部通过后方可发布。

## 关键约束
- 禁止重复开发简历解析 Skill、面试评价 Skill，必须直接复用平台现有 Skill 节点。
- AI 结果仅供参考，最终录用与审批结论由 HRBP / 业务负责人 / 审批人确认。
- 普通 BP 不得查看完整候选人联系方式；总经办 HR 可做带原因的临时解锁。
- 高管仅查看管辖范围报表和关键审批，不可修改简历或面试内容。
- 全流程必须保留站内待办、站内消息、短信通知和操作日志。
- 招聘网站前台只展示状态=已发布 的岗位；官网内容更新必须经过 CMS 预览后发布。

## 最终验收
- 页面、流程、权限、联动、AI、BI、H5、通知、日志全部与工作簿保持一致。
- 候选人手机端完成投递、面试查看、Offer签署、入职资料提交全链路验证。
- 招聘网站前台完成首页、职位列表、职位详情、校招专区、达人岗位专题、进度查询全链路验证。
- 需求审批通过后，必须自动触发渠道发布、人才库匹配、BI写入。
- Offer确认后，必须自动推送行政后勤任务和商学院新人课程任务。
