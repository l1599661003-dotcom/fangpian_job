# 手机工作台样式统一

日期：2026-09-25

## 设计与边界

- 延续暖金色品牌，使用深棕导航、暖灰背景、白色内容卡片；取消干扰阅读的重复背景纹理。
- 中文标题保留宋体层次，正文使用已内置的 OPPO Sans / 思源黑体，不下载字体。
- 正文与按钮按 14px、辅助说明按 13px、输入按 16px 设计；操作按钮至少 44px，主要提交按钮至少 48px。
- 导航不再持续占据长页面的顶部；原有横向菜单、权限过滤、当前用户及退出入口保留。
- 页面标题、筛选、统计、列表、空状态、表单使用一致的间距与边界；长列表优先随页面滚动。
- 延续面试评价的口述提纲；意向沟通保留单一AI原文输入、解析与人工确认交互。
- 新样式集中在 `source-app/mobile-workspace.css`，仅在不超过 760px 时生效；没有修改业务 JavaScript、接口、后端或数据库。
- 主工作台及人才评审入口均加载该样式。历史独立演示原型与上传的原始素材不重做。

## 验证范围

主页面：招聘概览、岗位、应聘者、简历详情、人才档案、人才库、内推、面试、Offer、定时任务、开发者中心、数据分析、设置。

页面布局覆盖 320×568、390×844、820×1180、1440×960；手机额外检查页面描述字号、按钮字号与点击高度、页面横向溢出。公开沟通表单另覆盖 390×380 的缩小可用高度。

交互回归覆盖沟通解析失败重试、口述提示切换、定向约面、邀请结果、面试评价草稿和提交、HR Offer、入职回访、部门群评审与权限操作等既有测试。

测试采用 mock 数据，不发送真实消息、不创建实际会议、不写入业务数据库。浏览器模拟不等同于真实 iOS/Android 软键盘验收；构建通过也不代表生产发布。

## 复验

先运行 `npm run build`，完成后运行 `node --test tests/*.test.mjs`。

页面截图与布局：`RF_CAPTURE_RESPONSIVE=1 playwright test -c playwright.config.mjs -g 'core workspaces'`。

全部交互：`playwright test -c playwright.config.mjs`；浏览器保持单 worker，必要时按测试名称分批执行。
