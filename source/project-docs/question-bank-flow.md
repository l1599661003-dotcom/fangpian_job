# 岗位与个人题库

## 入口和使用

- 电脑侧栏、手机工作台菜单新增“题库”，复用面试页面权限；导入、编辑、审核启用和停用复用 `manage_assessments` 操作权限。
- 分为岗位基础题库、我的题库。个人题目归属可信登录用户，不能用请求参数冒充其他面试官。
- 导入支持 Excel、CSV、TXT 和逐行粘贴。先选岗位、预览，再确认导入并启用。表头为题目、维度、参考答案、说明；文件最大 2MB，每批 1–200 题。
- 导入不覆盖已有题目；重复题跳过，部分失败逐行反馈，重试只补缺失题目。已停用的同名题需要显式恢复，导入不会绕过停用决定。
- 新题通过既有 `评分规则JSON.positionId` 绑定具体岗位，避免不同部门同名岗位串题；历史未绑定 ID 的题目仍按原岗位名称兼容。

## 面试题单

- 候选人确认参加后才能生成、推送，原天玑推送与重试规则保持。
- 先取启用的岗位基础题，再补本次面试官个人题。已配置岗位题且无沟通追问材料时，不调用 AI；未配置基础题或有意向沟通需补充追问时调用 AI。
- AI生成结果作为本次题单快照，同时留为题库草稿。无有效结果明确报错，不把空题单显示为成功。
- 手工生成通过后台任务执行，页面显示真实题单状态；观察要点可展开，保留 Word 导出。修改题库不影响已有面试快照。

## 入职评价与离职复盘

- 完成入职一月评价或试用期评价后，后台为岗位与原面试官分别生成完善建议；离职面谈与确认离职沿用既有入口，同时覆盖岗位题库。
- 反哺题均为待审核草稿，不自动改写或停用原题。复盘提示要求事实型、岗位相关、去身份化，不将离职本身视为能力不足。
- 入职评价任务状态持久化于既有 `扩展信息JSON.questionBank`；离职复盘沿用既有反哺状态字段。题库页显示处理中、失败任务，并为有入离职管理权限者提供重试入口。
- 处理已完成的同一评价不会重复生成；已成功完成的题库归属不重复生成，写入中途失败可以重试。后台任务仍采用现有进程内执行机制，不是持久队列；重启后处理中超过10分钟可重试。
- 仅对本次上线后完成的评价触发自动完善，不自动批量回填历史员工数据。

## 验证边界

- 本轮只读取真实字段定义，未导入真实题目、未触发真实员工复盘、未发送企微或天玑测试通知。
- 构建、内存数据库回归与模拟浏览器验证不代表已经发布或完成真实外部流程验收。
