# 月度招聘需求公开接口

其他平台用长期 API Key 查询招聘需求。密钥不会自动过期，主动轮换后旧密钥立即失效。

## 接口

```http
GET https://r5vd-1031.studio.fengbao.com/api/public/recruitment/monthly-hiring
```

| 项目 | 说明 |
| --- | --- |
| 方法 | `GET` |
| 鉴权 | 请求头 `X-API-Key` |
| 密钥 | 与简历公开接口共用，在开发者中心查看 |
| 有效期 | 长期有效，直到主动轮换 |
| 登录 | 不需要 |

## 参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `month` | 否 | `YYYY-MM`。不传时按公司日历取当前月 |
| `period` | 否 | `day`、`week`、`month`，默认 `day` |

`month` 在 2026 年使用公司月，不是自然月：

| 月份 | 统计区间 |
| --- | --- |
| 2026-10 | 2026-09-27 至 2026-10-24 |
| 2026-11 | 2026-10-25 至 2026-11-21 |
| 2026-12 | 2026-11-22 至 2026-12-31 |

其他年份没有公司月配置时，按自然月统计。

`period` 只影响汇总里的简历、面试、Offer、到岗统计窗口：

| 值 | 统计窗口 |
| --- | --- |
| `day` | 当天 |
| `week` | 本周一至周日 |
| `month` | 所选公司月 |

岗位需求、完成数和缺口始终按 `month` 汇总，不受 `period` 影响。

## 请求示例

```bash
curl "https://r5vd-1031.studio.fengbao.com/api/public/recruitment/monthly-hiring?month=2026-11&period=month" \
  -H "X-API-Key: rf_live_替换为实际密钥" \
  -H "Accept: application/json"
```

```python
import os
import requests

response = requests.get(
    "https://r5vd-1031.studio.fengbao.com/api/public/recruitment/monthly-hiring",
    params={"month": "2026-11", "period": "month"},
    headers={
        "X-API-Key": os.environ["RESUME_API_KEY"],
        "Accept": "application/json",
    },
    timeout=60,
)
response.raise_for_status()
data = response.json()
```

### 汇总字段

| 字段 | 说明 |
| --- | --- |
| `demand` | 当月需求人数合计 |
| `resumes` | 统计窗口内完成解析的简历数 |
| `interviews` | 统计窗口内有面试安排的候选人数 |
| `offers` | 统计窗口内已发送 Offer 的候选人数 |
| `actualOffers` | 当月计入完成数的 Offer 人数 |
| `arrived` | 当月实际到岗人数 |

### 岗位字段

| 字段 | 说明 |
| --- | --- |
| `positionId` | 岗位 ID |
| `department` | 部门 |
| `role` | 岗位名称 |
| `demand` | 需求人数 |
| `completed` | 已完成人数，按已发送 Offer 的候选人去重 |
| `remaining` | 剩余缺口，最小为 0 |
| `completionRate` | 完成率，0 到 100 的整数 |
| `completedAll` | 是否已完成全部需求 |
| `status` | 需求状态 |
| `priority` | `紧急`、`重要` 或 `储备` |
| `expectedArrivalDate` | 期望到岗日期，可能为空 |
| `latestArrivalDate` | 最晚到岗日期，可能为空 |
| `recruiter` | 招聘 HR |
| `backupRecruiter` | 备用招聘 HR |

只返回仍在招聘、需求已通过且人数大于 0 的岗位。已驳回、已停用和暂停招聘的岗位不返回。

接口不返回候选人姓名、联系方式、简历和当日活动明细。

## 错误

| HTTP | 原因 |
| --- | --- |
| 400 | `month` 不是有效的 `YYYY-MM` |
| 401 | 未传 `X-API-Key`、密钥错误或密钥已轮换 |

```json
{
  "statusCode": 401,
  "message": "X-API-Key 缺失、错误或已被轮换"
}
```

结果缓存 30 秒。同一参数在 30 秒内可能返回同一份数据。

## 密钥

1. 登录人才管理系统，打开开发者中心。
2. 复制当前 API Key。
3. 外部系统只把密钥放在服务端环境变量，不要写进前端页面或仓库。
4. 轮换密钥后，所有已接入系统都要同步更新；旧密钥立即失效。
