# 手机长表单滚动检查（2026-09-25）

## 问题与调整

- 意向沟通公开页原先限定为一屏高度，候选人介绍与提交说明占据上下区域，仅中间表单滚动。手机改为文档整体滚动，头尾随内容离开视口。
- 手机通用操作弹窗使用单一外层滚动容器；约面、简历人工评审、群评审回复列表取消内部独立滚动，人才详情取消内外两层定高滚动。
- 手机公开表单输入字号至少 16px，文本域至少 120px，提交区不悬浮遮挡输入。
- 调整仅作用于不超过 760px 的视口。桌面/平板原有布局、字段、接口、提交流程与通知逻辑保持不变。

## 验证范围

- 公开意向沟通：320×568、390×844、390×380；检查文档可滚动、文本域完整可见、页头能滚出视口、提交按钮可到达、提交数据和成功反馈。
- 390×380 为缩小可用高度的回归模拟，不等同于真实 iOS/Android 软键盘验证。
- 页面布局回归：概览、岗位、应聘者、简历详情、人才档案、人才库、内推、面试、Offer、定时任务、简历 API、分析、设置；覆盖手机、平板、桌面。
- 既有交互回归继续验证沟通 AI 解析失败重试与内容保留、定向约面、邀请结果提示、面试记录/评价、HR Offer 表单及群推送状态。
- 所有浏览器业务请求均使用测试数据；不触发真实邀请、群消息或业务记录写入。构建和测试不代表生产发布或真机验收。
